# Dataset card

## Primary task data: Shakespeare, Complete Works

| | |
|---|---|
| Source | Project Gutenberg eBook #100, *The Complete Works of William Shakespeare* |
| URL | https://www.gutenberg.org/cache/epub/100/pg100.txt (one file, fetched once on 2026-11-08 by `morrowglass data prepare --fetch`) |
| Raw file | 5,638,481 bytes, sha256 `eb61e33cab23dbe712ad57091ded6c7292ba91ac3bb2764f51a3223ec0068fe5` (the PG header says "Most recently updated: October 17, 2026"; a later PG revision will hash differently, and the manifest will show it) |
| Licence | The works are in the public domain in the USA. The Project Gutenberg header, footer and licence text are removed during processing, so the processed files contain only Shakespeare's text and no PG trademark. |
| Collection | Not scraped. A single public-domain file from the publisher's own cache URL. No personal data. |
| In git | Only the offline sample (`data/sample/shakespeare/`, ~320 KB) and the manifests with hashes. The raw and processed corpora are gitignored and rebuilt with `make data`. |

### Processing (`src/morrowglass/data/corpus.py`, preprocessing version 1)

1. CRLF→LF, Unicode NFC.
2. Typographic quotes, dashes, ellipses and NBSP mapped to ASCII. 263 non-ASCII characters remain across all splits (accented names etc.); the byte tokenizer handles them losslessly.
3. Strip trailing spaces; collapse 4+ blank lines to 3.
4. Remove the PG boilerplate between `*** START/END OF THE PROJECT GUTENBERG EBOOK ***`.
5. Split the body into its 44 works using the table of contents.
6. **Split by work**: with seed 1729, 3 plays go to validation and 3 to test; the rest go to train. The 6 poems (Sonnets, Venus and Adonis, …) always stay in train. Nothing is fitted on the full dataset: the BPE tokenizer and every n-gram baseline are trained on the train split only.

| split | works | bytes | contents |
|---|---|---|---|
| train | 38 | 4,557,058 | 32 plays + 6 poems |
| val | 3 | 425,674 | *As You Like It*, *Hamlet*, *Titus Andronicus* |
| test | 3 | 377,278 | *Macbeth*, *Pericles*, *Cymbeline* |

Exact hashes: `data/manifests/shakespeare.json`.

### Label semantics

This is language modelling. The "label" for position *t* is the token at *t+1*: the next UTF-8 byte
(byte tokenizer) or the next byte-level BPE token. Metrics are reported in **bits per UTF-8 byte**, so
models with different tokenizers can be compared.

There are no classes, so no class balance applies. The closest analogue is the byte frequency
distribution, and the unigram baseline captures it (4.75 bits/byte on validation).

There is no missing data. Empty lines and stage directions are kept as text.

### Leakage risks and guards

| risk | guard | test |
|---|---|---|
| A play in both train and eval | split by whole work; assert disjoint title sets | `test_full_manifest_splits_are_disjoint_by_work` |
| Stock lines repeated across plays | measured: line-level overlap of val/test lines (≥ 30 chars) with train is **0.04% / 0.02%** (3 and 1 lines) | `test_full_manifest_line_overlap_is_small_and_recorded` |
| Tokenizer fitted on eval text | BPE trained on the train split only | `tokenizer/tokenizers.py::get_tokenizer` |
| Baseline fitted on eval text | n-gram counts from train only | `experiments/runner.py::run_baselines` |
| Tuning on test | test is evaluated only by `morrowglass final-test`, which writes `reports/test_access_log.jsonl` | `test_training_reduces_held_out_loss` asserts training never evaluates test |
| Temporal leakage | not applicable (no time dimension) | — |
| Near-duplicate works | apocrypha/variant texts are not in PG #100; the 44 works have distinct titles | manifest `n_works` |

### Known limitations

- One author, one era, and early-modern spelling. The held-out plays are still in-domain: this tests generalisation to unseen plays, not to other English.
- 4.5 MB is tiny by modern standards. Larger models overfit or are undertrained (see `capacity`).
- Validation contains *As You Like It*, which is largely prose, so it is harder than verse-heavy plays. Validation is also not identically distributed with test (see `docs/RESULTS.md` for both).
- Normalisation to ASCII punctuation loses typographic information.

## Secondary track: synthetic digit-sum (mod 10)

Generated by `src/morrowglass/data/synthetic.py` with seed 4242. No external data. For example,
`3+9+4=6`. The model reads the expression and is scored only on the answer digit.

| split | terms | n |
|---|---|---|
| train | 3-6 | 60,000 |
| val_iid | 3-6 | 2,000 |
| test_ood_near | 8-10 | 2,000 |
| test_ood_far | 12-16 | 2,000 |

Every expression string is unique across all splits (`test_synthetic_no_expression_leaks_across_splits`).
The evaluation splits are drawn first, so train cannot contain them. There are only 1,000 possible
3-term expressions, so the 3-term part of train is small. Chance accuracy is 10%.

## Offline sample

`data/sample/shakespeare/{train,val,test}.txt` holds the first 240 KB / 40 KB / 40 KB of each processed
split, cut at a line boundary, with hashes in `data/sample/shakespeare/manifest.json`. It powers
`make smoke`, the CI checks and the `scarce` (data-starved) experiment arms.
